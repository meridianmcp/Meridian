8. Network use
Meridian Desktop sends network requests to two places.
(a) A Meridian server on this computer. Its address comes from the local_url setting and must be http on 127.0.0.1,
localhost or ::1. The desktop checks it with a request to its /health path, and reads RunPod status through it.
(b) The Meridian hosted service, at the hosted_url setting (https://usemeridian.us by default). This happens only in
Hosted mode. Hosted mode is used when you choose it, or when a hosted sign-in token is saved on this computer. In
Hosted mode the desktop sends requests there to check your account and to list your projects and sessions, using that
sign-in token.
The desktop has no RunPod address of its own. The RunPod key stays in the operating system credential store on this
computer. The Meridian server and the hosted service are separate programs, and this section does not cover their
network use.
